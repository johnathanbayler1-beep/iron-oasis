# 3D Gym Models

**Scenes:** Scene2GymReveal, Scene3PrivateExperience, Scene7 backdrop  
**Format:** GLB (binary GLTF with embedded textures)  
**Quality Levels:** Full (4-8 MB) + Optimized (< 1 MB)  
**Status:** Optional, post-launch  

## File Names Required

- `gym-space-2k.glb` — Full quality model
- `gym-space-2k-opt.glb` — Mobile optimized model

**Requirements:**
- Interior gym space
- Professional lighting
- PBR materials (dynamic lighting compatible)
- Matches camera choreography
- Realistic scale

See `ASSET_HANDOFF_GUIDE.md` for detailed specs and optimization guide.
