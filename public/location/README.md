**Dimensions:** 1200 × 800 px (landscape 3:2 ratio)  
**Format:** JPEG or WebP

- `location-exterior.jpg` — Building facade, entrance
- `location-gym-1.jpg` — Main gym interior
- `location-gym-2.jpg` — Training zone / private area
- `location-detail.jpg` — Equipment close-up
- `location-neighborhood.jpg` (optional) — Area context
